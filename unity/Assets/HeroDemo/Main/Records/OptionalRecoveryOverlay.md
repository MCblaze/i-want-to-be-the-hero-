# QP1 Optional and Recovery Overlay

Linked records: [Six-Zone Bubble Map](SixZoneBubbleMap.md) · [Critical Path](CriticalPath.md) · [Mechanic Resonance Table](MechanicResonanceTable.md)

Legend: blue recovery/checkpoint, amber optional test, red danger, gold reward.

| Location | Required? | Optional / recovery affordance | Constraint |
|---|---:|---|---|
| Trailhead x0–8 | Yes | Broad first landing and runway | Safe landing ≥2 wide |
| Broken Steps x8–17 | Yes | Recovery shelf after the hazard; short-step alternate | Required gap ≤2.75; no >1.8 pre-Spark step |
| Canopy Lift x17–27 | Yes | Teal platform crossing; checkpoint at 24.55 | Moving platform idles at start; checkpoint is blue |
| Spark Shrine x27–34 | Yes | Spark preview is intentionally unreachable pre-Spark; double-jump test surface | Spark x≈31 is gold; post-Spark step ≤3.0 |
| Gate Return x34–41 | Yes | Low sword lane, high wand lane, optional backflip cache | Backflip never required; both target lanes readable |
| Guardian Court x41–51 | Yes | Respawn to checkpoint after a failed approach | Clear boss floor ≥9 units; purple threshold |

Recovery rules: falling or hazard contact returns to the last safe checkpoint; the checkpoint is before Spark, so Spark state remains a meaningful progression test. The optional stretch is visibly signposted and must have a reachable recovery shelf; it cannot block gate access.
