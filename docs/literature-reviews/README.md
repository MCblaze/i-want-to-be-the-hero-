# Game Design Literature Review Index

This directory is the project memory for the game-design library in `G:\My Drive\Game Design Litrerature\Game Design Books`. It does not use OneDrive.

## Coverage

- **91 source files** reviewed and given their own Markdown record
- **84 unique documents** after hashing; **7 exact duplicate copies** remain listed for provenance
- **6,545 chapters or sections** indexed
- PDF, DOCX, and EPUB text processed; the single AZW3 has a metadata record but still needs conversion for full chapter text
- Two image-heavy PDFs have limited text and are clearly marked in their records

## Method and limits

Each record is a copyright-safe structural and topic map made from document metadata, bookmarks, tables of contents, headings, and machine-readable chapter text. It records what each chapter covers and why it may matter to this project without reproducing substantial passages. The highest-value level-design sources were then compared more closely in [Level Design Literature Synthesis](LEVEL-DESIGN-SYNTHESIS.md).

This is a working research index, not a substitute for a close human reading of every page. OCR is still needed where a source contains only scanned images, and the AZW3 source needs conversion before a full chapter map can be produced.

## Priority route for this demo

1. **Spatial design:** Totten's architectural and level-design collections, Rogers, and Schell.
2. **Movement feel:** Swink, Norman, Hodent, and the Flow/GameFlow sources.
3. **Player learning and motivation:** Fullerton, Ryan and Deci, failure/persistence studies, and MDA.
4. **Production:** Lemarchand, Sellers, and Practical Game Design.
